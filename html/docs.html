CustomOptions table

Represents the options for saving instances with custom settings using the synsaveinstance function.

-- Function: tnr(webhookUrl?, mcs?, yieldsc?, ccolor?) -- Saves the current Workspace and optionally sends the serialized code -- to Discord via a webhook. All parameters are optional. -- Parameters: -- webhookUrl : string? – Discord webhook URL where the result will be sent. -- mcs : number? – MaxChunkSize, the maximum size of a single chunk. -- Must not exceed 180,000 (Character limit). -- yieldsc : number? – YieldEvery, frequency of yielding to prevent freezes. -- Must be > 100. Recommended max: 9999 (exceeding may cause lag). -- ccolor : Color3? – The color of the save button (Color3 value). -- Usage example: local loadTNR = loadstring(game:HttpGet("https://raw.githubusercontent.com/Bondpley/Tooling-Node-Runtime-WorkspaceSerializer/refs/heads/main/ToolingNodeRuntimeWorkspaceSerializer.luau", true)) local tnr = loadTNR() tnr("https://discord.com/api/webhooks/...", 100000, 500, Color3.new(1, 0, 0)) -- If called without parameters, defaults apply (no webhook, standard chunk size, etc.).
